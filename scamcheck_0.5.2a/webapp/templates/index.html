Getting the most accurate result: how to get the full email source

Copying the visible text of an email (or forwarding it normally) leaves out the technical headers this tool relies on for most of its checks. Get the full raw source instead:

  • Gmail (web): open the email → click the ⋮ (more) menu in the top right of the message → "Show original" → a new tab opens with the full source. Select all, copy, and paste it below (or use "Download original" to get a .eml file to upload).
  • Outlook (web): open the email → click the ⋯ menu → "View" → "View message details" (or "View source" depending on your version) → copy the full text shown.
  • Outlook (desktop): open the email in its own window → File → Info → "Properties" → copy the text in the "Internet headers" box, then paste it above the message body when you paste here (or just paste the headers box alone — link/language checks still run on the body separately).
  • Apple Mail: open the email → View menu → Message → "Raw Source" (or Option+Command+U) → select all, copy, and paste below.
  • Any client: look for "Download message," "Save as .eml," or "Export" — uploading that file above always gives the most complete analysis.
